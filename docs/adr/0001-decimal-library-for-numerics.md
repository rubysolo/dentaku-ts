# Use a decimal library for all internal arithmetic

Ruby Dentaku's arithmetic runs on BigDecimal, so `0.1 + 0.2 = 0.3` exactly and `5 / 2 = 2.5` exactly. IEEE-754 `number` cannot reproduce this, and exact decimal arithmetic is a defining feature of the formula language that existing corpora rely on (equality comparisons against decimal constants). We therefore use a decimal library (decimal.js) as the internal numeric type for all literals, arithmetic, and comparisons, accepting one runtime dependency in an otherwise dependency-free library. Plain `number` (rejected: silent float drift breaks equality comparisons in ported formulas) and a pluggable numeric backend (rejected: genericizing every AST node is the largest complexity multiplier in the port for a niche benefit) were considered.
